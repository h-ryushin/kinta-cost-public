# KintaCost（きんた 原価計算）

焼肉店「きんた」で、材料原価とメニュー原価を手作業で把握していた課題を解決するために個人開発した、原価計算のWebアプリです。仕入れ価格を変えると、その材料を使うメニューの原価と原価率がすぐに更新されます。実際の店舗で運用しています。

> このリポジトリは公開用です。お店の実データ・運用ドキュメント・本番環境の設定は含めていません（`wrangler.jsonc` の Supabase の値はプレースホルダーです）。

## 主な機能

- 材料の仕入れ価格と量（g・ml・個・本など）から、1単位あたりの単価を計算
- メニュー・仕込み品ごとの原価と原価率を自動計算（歩留まり・税込/税抜にも対応）
- 仕入れ価格を変えたときに、影響するメニューと原価の変化を一覧で表示
- 秘密レシピのブラウザ内暗号化（AES-256-GCM）。管理者以外は開発者を含めて中身を読めない
- パスキー（WebAuthn PRF）による顔・指紋での鍵の解錠、パスワード＋認証アプリの二段階認証
- Supabase の行レベルセキュリティで、管理者・社員の権限をデータベース側で強制

## 使用技術

Next.js / TypeScript / Tailwind CSS / Supabase（PostgreSQL・Auth・RLS・Edge Functions）/ Cloudflare Workers / Web Crypto API / WebAuthn / Vitest / GitHub Actions

## 工夫したところ

- **使う人に合わせた作り直し**：最初の画面が実際に使う方には分かりにくかったため、業務の手順と最終的に見たい数字をヒアリングし、試作品を早めに見せて意見をもらう進め方に変えました。
- **データを守る設計**：レシピはお店の大事な秘密なので、暗号化はブラウザの中だけで行い、鍵はサーバーに置きません。設計の考え方は [docs/security.md](docs/security.md) にまとめています。
- **安心して直し続けられるテスト**：原価計算・暗号化・権限まわりに300件以上の自動テストを用意し、push のたびに GitHub Actions で実行しています。RLS のテストは `supabase/tests/` にあります。

## 動かし方

Node.js 24 以上が必要です。

```bash
npm install
npm run dev
```

| コマンド | 内容 |
| --- | --- |

| `npm run check` | 型チェック・lint・テストをまとめて実行する |
| `npm test` | テストを実行する |
| `npm run build` | 公開用のファイルを書き出す |
